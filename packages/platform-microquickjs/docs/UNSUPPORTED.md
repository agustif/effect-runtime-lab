# Unsupported and deferred

## Explicitly deferred
- native `FileSystem`, `HttpClient`, `Stdio`, and `RuntimeMain` services
- production-style host-backed runtime proofs
- artifact and dependency scorecards

## Explicit non-goals for the current slice
- pretending the WASM sandbox is equivalent to the native QuickJS or txiki adapters
- claiming full runtime parity before a host bridge contract exists
